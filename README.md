# ProControl
Android-приложение для ежедневного учёта чистой продукции, брака и сдельного заработка.

- Ежедневная запись чистой продукции и брака в тоннах.
- Нулевой тоннаж разрешён.
- Настраиваемые тарифы за тонну.
- Начисление за смену и расчётный период.
- Средний заработок за календарный день, включая дни без выпуска.
- Ручное закрытие периода с сохранением итогов и среднего заработка в архив.
- Локальное хранение данных на телефоне.

Формула начисления: чистая продукция × тариф чистой продукции + брак × тариф брака.
Стартовые тарифы: 80 сом/т и 75 сом/т. Их можно изменить в приложении.

APK собирается GitHub Actions. Результат доступен как артефакт ProControl-debug-apk во вкладке Actions.
